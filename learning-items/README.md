# Learning items

Tracks Python-specific knowledge gaps surfaced while building Huginn, one
file per topic (`template.md`). Local for now; each item is meant to sync to
a Jira ticket later, at which point its `Jira:` field gets filled in.

Naming: `kebab-case-topic.md`, no numbering, topics aren't sequential or
dependent on each other the way ADRs are.

Status values:

1. `Backlog`: surfaced, not yet worked through.
2. `Learning`: actively being read/practiced.
3. `Done`: understood well enough that this file is a reference, not a
   to-do.

When to add one: a Python-specific concept (language, stdlib, tooling,
idiom) comes up that assumes background the project's engineer doesn't have
yet (Java/C# experience, new to Python). Huginn's own architecture/design
decisions don't belong here, those go in `adr/` instead.
